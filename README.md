# Dithus app

A lightweight, real-time AI companion for Wayland desktops.

It reads your screen through periodic screenshots, listens to your microphone,
and answers in a small always-on-top window. No live screen-share negotiation,
no permission picker loops.

See `docs/spec-mvp.md` for the MVP spec.

## Status

Scaffolding phase. Milestone 1: CLI core pipeline
(screenshot plus question yields a model answer in the terminal).
